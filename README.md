# 🌸 Sushi – Your Tiny Desktop Coding Companion

> A cute desktop companion that keeps you motivated while you code.

## ✨ About

**Sushi** is a fun desktop companion inspired by the idea of having a tiny version of myself on my screen while I work.

Instead of downloading another productivity app, I built my own companion using **Electron.js**. Sushi stays on the corner of the desktop, performs cute animations, gives motivational messages, and reminds you to stay hydrated while coding.

This project was built as part of my **#30DaysOfBuilding** challenge to improve my development skills by creating real-world projects.

---

## 🚀 Features

- 🌸 Cute desktop companion
- 💻 Always stays on top
- 🖱️ Draggable anywhere on the screen
- 💬 Random motivational dialogues
- 👋 Interactive animations
- 💧 Water reminders
- 😄 Multiple character poses
- ⚡ Lightweight Electron application
- 🎨 Transparent desktop window
- 💾 Remembers last position

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/sushi-desktop-companion.git
```

Go to the project folder

```bash
cd sushi-desktop-companion
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```
